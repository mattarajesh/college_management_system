# 🎓 College Management System

A College Management System built using **Python** and **Django**. This project helps manage student records through a simple web interface and follows the Django MVC (MVT) architecture.

## 🚀 Features

### Student Module
- 🏠 Home Page
- 📋 Student Dashboard
- ➕ Add Student
- 📄 Student List
- 👁️ View Student Details
- ✏️ Update Student
- ❌ Delete Student
- 🔍 Search Student
- 📃 Pagination
- ✅ Success Messages
- 🎨 Bootstrap UI

## 🛠️ Technologies Used

- Python 3
- Django
- HTML5
- Bootstrap 5
- SQLite3
- Git & GitHub

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/college_management_system.git
```

### Go to the project folder

```bash
cd college_management_system
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install django
```

### Apply migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Run the server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
